welcome.py — Contains a welcome() function that returns a greeting message for a given name.
toolbox.py — Contains three functions: double() doubles a number, is_pass() checks whether a score is 50 or more, and greet() creates a greeting with an optional greeting parameter.

The hardest function to write was greet() because it uses a default parameter. It helped me understand how a function can use "Hello" automatically when no greeting is provided.
